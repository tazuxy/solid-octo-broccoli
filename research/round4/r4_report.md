# 第4ラウンド 検証報告（朝スキャルピング型EA と 東京仲値アノマリー）

対象データ：histdata の1分足（2005〜2024年、EST＝UTC−5 固定、夏時間なし）から作った5分足と、既存の日足（bars_full）。日本は夏時間がないので、**日本時間（JST）＝ histdata の時刻 ＋ 14時間**（通年）です。スワップ（金利差調整額）は含めていません。価格は histdata の **Bid（売値）だけ**です。

## 1. 結論

- **事前に決めた8本（S1：4本、S2：4本）は、すべて不合格です。** 合格基準を全部満たした案はありません。
- **S1（朝スキャ：RSI／ボリンジャーで逆張り、日本時間 07:30〜08:45 にエントリー）**
  - コストを引く前（グロス）は、4本すべてはっきりプラスです（1回あたり平均 +1.1〜+2.2 pips、t値 18〜41）。
  - しかし、コスト1倍（通常の往復コスト）を引いた時点で、4本すべてマイナスになります。基準のコスト2倍では、6区分（2グループ×3期間）のすべてで平均R がマイナスです。
  - 損益ゼロになるコストは、通常コストの 0.49〜0.88倍です。つまり、**この足で見える値幅の取り方では、普通のスプレッドを払うと利益が残りません。**
  - 利益（グロス）は、ロールオーバー直後の 17:30〜17:55 EST（JST 07:30〜07:55）に集中しています。ここは実際のスプレッドが一番広い時間帯なので、実運用ではさらに不利と考えます。
- **S2（東京仲値、USDJPY）**
  - 「08:00 に買って 09:55 に決済」（a）も、「09:55 に売って 11:00 に決済」（c）も、グロスではプラスでした（a：+0.83 pips、c：+0.56 pips、1回あたり）。ただし往復1.0 pip のコストを引くとマイナスです。
  - **ゴトー日だけ買う案（b）が最も近い案です。** グロス +1.84 pips、ネット（コスト1倍）で平均 +0.039R、t値 2.40、3期間すべてプラスでした。
  - それでも、合計R÷最大DD が 2.47（基準3以上）で届きません。コスト2倍では平均R −0.010 とマイナスになります。したがって**不合格**です。
  - 2014〜2018年は5年続けてマイナスで、資産の最高値を更新できない期間が約8.3年（3,038日）ありました。
- 合格案がないため、事前の手順どおり、次の作業は**行っていません**。「取引しない条件」の検討、ポートフォリオ・シミュレーション、資産曲線の図（r4_equity.png）、モンテカルロ、EA（r4_EA.mq5）の作成です。
- 結果を見たあとで条件や数値を変えることもしていません。後半にあるコスト感度の表は、参考として示すだけです。合否の判定には使っていません。

## 2. 第4ラウンドの位置付け（サイト調査から取り出した仮説）

- 第0〜第3ラウンド（事前に決めた上限3回）で、合格案はありませんでした。今回は、それとは別に依頼された追加ラウンドです。
- 方針は「EA開発サイト約20件（日本の証券会社の解説ページ、MQL5の商品・ブログ、大学の学生論文）で最もよく見かけ、ルールが具体的で検証できるロジックを2つ選ぶ」ことです。
- **S1 朝スキャ／ナイトスキャルパー**：個人向けEAで最も多い種類です。各サイトの説明は次のようにまとまります。
  - NY市場が閉まったあとの閑散時間はレンジになりやすい。
  - そこで RSI やボリンジャーバンドの行き過ぎを逆張りする。
  - ポジションは1つずつ持ち、スプレッドフィルターを使い、ロールオーバー時刻（スプレッドが3〜5倍に広がる）は避ける。
- **S2 東京仲値（09:55 JST）アノマリー**：日本の個人投資家に人気で、学生論文（神戸大学、早稲田大学MBA 2020年）に裏付けがあります。
  - 論文の主張は「USDJPY は仲値に向けて上がり、仲値のあとに下がる。特にゴトー日に強い。USDJPY 特有の現象」というものです。
  - 輸入企業がドルを買う注文が仲値に集まる、という実需の説明があります。
- 試したのは合計8本です（S1：4本、S2：4本）。夜の時間帯以外で同じルールを使う「プラセボ」とクロス円での確認は、参考として示すだけで、選択には使っていません。第0〜3ラウンドまでの試行回数も足すと、偶然に1本だけ合格する可能性は無視できません。そのため、S1 の t値基準は 3.0 に引き上げてあります。

## 5. 最も近い案（S2 b：ゴトー日の仲値前買い）とその弱点

**良い点**

- グロスでは、3期間すべてではっきりプラスです（1回あたり +1.74／+0.97／+3.04 pips）。コスト1倍でも3期間すべてプラス、t値 2.40 でした。
- 「ゴトー日に強い」という実需の説明と整合します。同じ 18:00 EST 開始・115分保有の買いで比べると、ゴトー日は +1.84 pips、それ以外の日は +0.41 pips でした。
- 他の時刻に始めた同じ長さの保有の平均（24通り）は、ゴトー日 +0.34 pips、それ以外 −0.01 pips です。つまり、ゴトー日全体の円安傾向を差し引いても、仲値前の2時間に約 +1.5 pips の上乗せがあります（r4_s2_control.csv）。

**弱点（不合格の理由）**

1. **1回の値幅が小さい**：平均 +1.84 pips に対して、往復コストは 1.0 pip です。コストが少し変わるだけで結果が大きく変わります。コスト2倍（2.0 pips）では全体がマイナスです。
2. **ドローダウンが長い**：合計R ÷ 最大DD は 2.47 です。2014〜2018年は5年続けてマイナスで、最高値を更新できない期間は約8.3年ありました。2012〜2018年の期間平均は +0.003R で、ほぼゼロです。
3. **取引回数が少ない**：年に約74回です。1回の期待値は約 +0.84 pips（ネット）で、年間では約 +60 pips 程度にしかなりません。
4. **ゴトー日の定義が近似**：日本の祝日を考慮していません。祝日に当たるゴトー日は本来は前営業日に繰り上がりますが、この検証ではそのまま平日として扱っています。また、仲値の公表がない日（年末年始など）も含まれます。
5. 仲値の需給は、2010年代半ば以降は弱まったと言われます。2012〜2018年の弱さはこれと整合しますが、2019年以降に戻った理由ははっきりしません（円安トレンドの影響を含む可能性があります）。

## 7. 限界

- **Bid だけのデータです**：Ask（買値）がないので、実際のスプレッドの広がり、特にロールオーバー前後は再現できていません。S1 のグロス利益の一部は、Bid だけで見ていることによる見かけのものの可能性があります。
- **コストは固定値です**：往復コストは時間帯によって変えていません（S1 は2倍、S2 は1倍を一律に適用）。スリッページ、約定拒否、ストップレベルの制限は入れていません。
- **5分足の中の値動きの順序は分かりません**：損切りを先とする保守的な仮定を置きました。該当は 0.17% なので、影響は小さいです。
- **祝日カレンダーを使っていません**：日本の祝日も、米国の祝日・経済指標（雇用統計など）も考慮していません。年末年始やクリスマスの薄い相場も含まれています。
- **スワップは含めていません**：S1・S2 とも保有時間が短く（S1 は平均20〜40分、S2 は1〜2時間）、ロールオーバー時刻をまたがないので、影響はありません。
- **多重検定の問題があります**：第0〜第4ラウンドを通じて、多くの案を同じデータで試しています。S2 b の t値 2.4 は、試行回数を考えると強い証拠とは言えません。
- histdata の時刻は EST 固定と仮定しています（第0〜第3ラウンドと同じ）。
