# 第2ラウンド 検証報告（未使用データ 2005〜2011年での一発確認）

対象：histdata の1分足から作った足（EST＝UTC−5 固定、夏時間なし）。コストは第0・第1ラウンドと同じ COST_PIPS（往復、変更なし）。スワップ（金利差調整額）は含めていません。

## 1. 結論

- **事前に固定した5つの候補（P1〜P5、P5 はルールCとEの2本で計6本）は、すべて不合格です。** 合格基準（a〜e）を全部満たした案はありません。
- 第1ラウンドの後で「向きを逆にすると良さそう」と見えた **P1（12週リバーサル）は、未使用の 2005〜2011年では逆にマイナス**でした。
  - 年率 −4.0%（USD建て群 D）、−4.5%（クロス群 C）。どちらも年率8%ボラ換算です。
  - 2008年の1年だけで −24% でした。
  - 第1ラウンドで見えたプラスは、2012〜2024年に固有のもの（またはデータを見てから向きを決めたことによる偶然）だったと考えます。
- **P2（1週リバーサル）は、2005〜2011年では D・C ともプラス**でした（D +5.5%、C +3.3%、合算 t値 1.34）。
  - ただし t値の基準（1.5以上）に届きません。
  - 新しい約定時刻（月曜 08:00 EST）にすると、2012〜2024年はマイナスになります（t値 −0.61）。
  - 2005〜2024年の通算は t値 0.59、累積/最大DD 0.61 で、基準（2.0、3）を大きく下回ります。
- P3（P1とP2の半々）、P4（ドンチアンH4＋フィルター）、P5（ダイバージェンス ルールC・E）は、どれも 2005〜2011年でマイナスか、ほぼゼロでした。
- **合格案がないため、事前の手順どおり、次の作業は行っていません。**
  - 「取引しない条件」の検討、5%／8%運用シミュレーション、ブートストラップ
  - EA（r2_EA.mq5）の作成
  - 結果を見てから条件やパラメータを変えることもしていません。
- 2012〜2024年の数値は、旧来の約定時刻（日曜17:00）では第0・第1ラウンドと**完全に一致**しました（再現確認済み）。

## 2. このラウンドの目的（未使用データでの一発確認）

- 第0・第1ラウンドでは、2012〜2024年のデータを設計にも検証にも使いました。事前登録した案で合格したものはありません。
- 「近かった案」のいくつかは結果を見たあとに見つけたものです。そのため、同じデータで良く見えても証拠になりません（データスヌーピング）。
- 今回は、これまで一度も使っていない 2005〜2011年の足で、**事前に固定した案を、パラメータを変えずに一度だけ**確かめました。この期間には 2008年の金融危機と 2010〜11年の欧州債務危機が含まれます。
- 2005〜2011年と 2012〜2024年をつないだ連続データ（bars_full）も作り、指標の計算が途切れないようにしました。

## 3. 事前固定の候補と判定基準

### 3.1 候補（定義は第0・第1ラウンドのコードそのもの）

- **P1 12週クロスセクション・リバーサル**：第1ラウンド H1a の売買の向きを逆にしたものです。
  - 8通貨を「直近1週を除く12週のリターン」で順位付けします。下位2通貨を買い、上位2通貨を売ります。
  - 保有は1週間です。各サイドの中は、20日ボラティリティの逆数で同じリスクになるように配分します。
  - 実装は2通りです。D は USD建て7ペア、C はクロス10ペア（USD を除く7通貨、最小コストの線形計画で分解）。
- **P2 1週クロスセクション・リバーサル**：第1ラウンド H1b と同じです。
- **P3 P1とP2の半々**：各脚を事前に年率8%のボラティリティに合わせ、0.5 ずつ足します。ボラティリティの推定には、直前52週の実現ボラティリティ（最低13週、1週ずらし）を使います。
- **P1〜P3 の約定（今回変更・固定）**：
  - 判断は金曜 NY 終値で行います。
  - 約定は翌営業日（通常は月曜）08:00 EST の H1 足の始値です。その日 08:00〜17:00 に足がない場合は、直前の H1 終値を使います。
  - 保有リターンは、月曜08:00から翌週の月曜08:00までです。
- **P4 ドンチアン H4**：N=50 のブレイクで入り、25本チャネルで決済します。初期SL は 2ATR です。ATR比が 0.8 未満なら見送り、月間 −5R で新規エントリーを停止します（第0ラウンドのコードと同じ）。
- **P5 ダイバージェンス**：ホールドアウト検証のルールC とルールE です（holdout.py／holdout_iter.py と同じ）。

### 3.3 結果を見る前に決めた細かい取り扱い

- **ウォームアップ**：各ペアのデータの最初の6か月は採点しません。
  - ポートフォリオでは、必要なペアがすべてウォームアップを終えた週から採点します。D は NZDUSD（2005-08開始）に合わせて 2006-02-12 以降、C は CADJPY（2007-03開始）に合わせて 2007-09-18 以降です。
  - このため、実際に採点された最初の週は次のとおりです。D は 2006-02-27、C は 2007-10-01（P3 の C は 2007-11-12）。2005年は採点されていません。
  - AUDNZD は、最初の6か月はクロスの組合せに使っていません。
- **データの修正（データの誤りだけを理由に決めたもので、戦略の結果は見ていません）**：
  - AUDJPY の 2005-05-01〜05-15 は、他の銘柄の価格が混ざっていました（0.67〜136 の値）。この期間は削除しました。
  - 1分足の終値の前後61分の中央値から 10% 超離れた異常値を削除しました。該当は AUDUSD・USDCHF・NZDUSD・GBPCHF の各1〜2本です。
  - 2012〜2024年のデータには手を加えていません。
- **AUDJPY の欠損**：元のデータでは 2012年1〜9月と 11〜12月が欠けています。連続データでは、10日を超える欠損の間はその銘柄を「なし」として扱いました。取引単位型では、欠損の後6か月を再ウォームアップとして採点から外しています。影響があるのは 2012〜13年の数件だけです。
- **P4 のコスト1.5倍**：コストを増やした R で月間停止の判定をやり直しています（第0ラウンドと同じ手順）。
- **P1〜P3 のコスト**：P3 では P1 と P2 の売買を相殺せず、それぞれにコストをかけています（保守的な扱い）。

## 6. 最も近い案とその弱点

**最も近いのは P2（1週リバーサル）です。** 2005〜2011年では、5基準のうち (a) と (d) を満たしました。

- 良い点：
  - 未使用期間で D（+5.5%、t 1.67）、C（+3.3%、t 0.86）の両方がプラスでした。
  - 通貨別でも15項目中13項目がプラスで、特定の1通貨だけに頼った結果ではありません。
- 弱点：
  - 合算の t値は 1.34 で、1.5 に届きません。
  - プラスは 2007年（+12.7%）と 2009年（+17.9%）に集中しています。どちらも危機前後でボラティリティが高く、行き過ぎの戻りが大きかった年です。2008年と 2010年はマイナスでした。
  - 現実的な約定（月曜08:00）にすると、2012〜2024年は t値 −0.61 のマイナスでした。2012年以降、この効果は消えているか、ごく小さいと見られます。2021〜2024年は4年中3年がマイナスです。
  - 売買量が多く（名目の約2.6倍／週）、コスト2倍では通算がほぼゼロ（t 0.05）になります。
  - 通算 2005〜2024年の最大DD は −25.8%（8%ボラ換算）で、新高値まで最長115か月かかりました。低ドローダウンの EA という目的には合いません。

**P1（12週リバーサル）について**：

- 第1ラウンドで、結果を見てから向きを逆にして見つけた案です。未使用期間では明確にマイナスでした（t −1.24、15項目中14項目がマイナス、2008年 −24%）。
- 「後から見つけた良い結果は、新しいデータで再現しないことが多い」という典型例です。

**P4・P5 について**：

- P4（ドンチアン）は 2005〜2011年に平均 −0.080R でした。通算のプラスは 2015年の SNB の1取引と 2024年に頼っています。
- P5 ルールE は、2012〜2024年の t 2.04 が 2005〜2011年では −0.93 になり、再現しませんでした。

**スワップについて**：

- バックテストはスワップを含みません。
- リバーサル型は「下がった通貨を買い、上がった通貨を売る」ため、高金利通貨と低金利通貨のどちらを持つかが週ごとに変わります。
- 2005〜2008年は金利差が大きかった時期（例：NZD・AUD と JPY の差が5〜7%）なので、スワップの影響は年率で数%に達しえます。今回は数値にできていません。

## 7. 限界

- **データ**：histdata の価格は1つの配信元の値です。2005〜2011年のデータには、混入や異常値が少数ありました（3.3節で修正）。他にも見つけていない誤りが残っている可能性があります。実際のブローカーの約定価格・スプレッドとは異なります。
- **期間の短さ**：未使用期間の採点は、D で約5.9年（305週）、C で約4.3年（222週）です。NZD・CAD・AUDNZD のデータ開始が遅いためです。週次の t値 1.5 を確かめるには短めの期間で、偶然のぶれが大きくなります。
- **時刻**：EST 固定（夏時間なし）です。月曜08:00 EST は、夏の間は実際の NY の 09:00 に当たります。
- **損益の計算**：決済通貨から口座通貨への換算は無視しています。通貨別の寄与は近似値です。
- **ボラの調整**：年率8%への調整は、成績比較のための事後の一定倍率です（P3 の脚の合成だけは事前推定です）。
- **多重検定**：第0〜第2ラウンドで多数の検定を行いました。今回の6本は一発の確認ですが、それでも1本くらいは偶然で t≈1.5 になりえます。
- **コストとスワップ**：コストは COST_PIPS の固定値です。2008年のような荒れた相場での実際のスプレッドの広がりは入っていません（実際の成績はさらに悪いはずです）。スワップは未考慮です。
