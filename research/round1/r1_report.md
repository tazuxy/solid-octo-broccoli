# 第1ラウンド 検証報告（ポートフォリオ型・季節性仮説）

対象期間 2012-01〜2024-12、histdata の足（EST＝UTC-5 固定、夏時間なし）。コストは第0ラウンドと同じ COST_PIPS（往復、変更なし）。スワップ（金利差調整額）は全く含めていません。

## 1. 結論

- **事前に固定した5基準をすべて満たした案は、6案（H3の半分ずつの2本を含め計7本）の中に一つもありません。** 第1ラウンドは「不合格」です。
- 合格案がないため、「取引しない条件」の分析、5%/8%運用シミュレーション、モンテカルロ、EA 実装の詳細設計は行っていません（事前の手順どおり）。
- 結果の要点：
  - **H1a（通貨の12週モメンタム）は逆に損失**。4区分すべてマイナス、週次 t値 −2.01。コストを除いても（グロス）マイナスで、2012〜2024年の主要通貨では「勝っている通貨を買う」はむしろ負けていました。
  - **H1b（1週リバーサル）** は設計8通貨側（D）では IS・OOS ともプラスでしたが、クロス側（C）はほぼゼロ。t値 0.43 と弱いです。
  - **H2（分散型トレンドフォロー）** は年率 +0.6% 程度で、利益のほぼ全部が 2015年1月15日の SNB（スイス中銀）ショックの1週でした。この週を除くと t値 −0.2 でマイナスです。
  - **H3（自国通貨は自国の取引時間に安くなる）** は、コスト控除前でも効果がほぼゼロ（t値 0.94）。1日2回の売買コストで大きくマイナス（年率 −16%、t値 −7.2）です。

## 2. 第1ラウンドの仮説と理由（第0ラウンドから何を捨て・変え・加えたか）

第0ラウンドでは、1通貨ペアごとに「いつ入って、いつ出るか」を決める指標ルールを 27種類試し、すべて不合格でした。コスト控除前の優位性もほぼゼロで、良く見えた結果は少数の外れ値（JPYクロスの買い＝キャリー、SNBショックの1取引 +153R）に頼っていました。

- **捨てたもの**：1ペア単位の売買タイミング規則（ボリンジャー＋RSIダイバージェンス、ドンチアン、移動平均クロス、RSI(2) など）と、それに付ける「取引しない条件」の探索。
- **変えたもの**：評価の単位を「1回の取引のR」から「ポートフォリオの週次リターン」に変更しました。複数の通貨・ペアに同時に持ち高を持ち、毎週組み替える形です。
- **加えたもの**：経済的な理由があり、学術研究で報告されている3つの効果。
  - **H1 通貨間の相対モメンタム／リバーサル**：8通貨（USD EUR GBP JPY AUD CAD CHF NZD）の強さを、均等加重バスケットに対して比べます。毎週金曜NY終値で順位を付け、上位2通貨と下位2通貨を売買します。
    - a = 12週モメンタム（直近1週を除く）。上位を買い、下位を売ります。
    - b = 1週リバーサル。下位を買い、上位を売ります。
    - 保有は1週間です。各サイドの中で、20日実現ボラティリティの逆数で同じリスクになるように配分します。
    - 実装は2通り（独立した2群）です。
      - D：USD建て主要7ペアだけを使います。
      - C：クロス10ペアだけを使います。USDを含めず7通貨で順位付けし、通貨の持ち高を最もコストが安いクロスの組合せに分解します（線形計画）。
  - **H2 分散型時系列モメンタム（マネージド・フューチャーズ型）**：18銘柄それぞれについて、1・3・12か月リターンの平均の符号を売買方向とします。60日ボラティリティで各銘柄のリスクを揃え、60日共分散でポートフォリオ全体を年率8%に合わせます。毎週組み替えます。
    - b は JPYクロス5本と XAU を除いた版で、キャリーへの依存を確かめるためのものです。
  - **H3 日中の季節性（Breedon & Ranaldo 2013）**：「自国通貨は自国の取引時間に下がる」という仮説です。時間帯の定義は次のとおりです。
    - 米国時間 08:00–16:00 EST（USD・CAD）
    - 欧州時間 03:00–08:00 EST（EUR・GBP・CHF）
    - アジア時間 19:00–02:00 EST（JPY・AUD・NZD）
    - 売買の方向は、各ペアの2通貨のうち「自国時間にある方を売る」です。
    - 使うのは D の6ペア（EURUSD GBPUSD USDJPY AUDUSD USDCHF NZDUSD）と、C の4ペア（EURJPY GBPJPY EURAUD CADJPY）です。
    - 2通貨が同じ地域にあり方向が決まらないペアは除外しました：USDCAD、EURGBP、EURCHF、GBPCHF、AUDNZD、AUDJPY、NZDJPY。XAUUSD は通貨ではないため除外しました。
    - 「半分」の定義は2つです。
      - W半分＝西側通貨（USDペアではUSD）の自国時間に、その通貨を売ります。USDペアでは「米国時間に外貨を買う」になります。
      - E半分＝東側通貨の自国時間に、その通貨を売ります。
    - H3a は両方を合わせたものです。指示どおり、IS で良かった方の半分を選ぶことはせず、両方を別々に報告しています。

共通の約束事（先読みなし）：

- 判断には、その週最後の日足終値（通常は金曜17:00 EST）までのデータだけを使います。
- 約定は次の日足の始値（日曜17:00 EST）とし、保有リターンは始値から翌週の始値までです（週末のギャップも含みます）。
- コストは、組み替えで動いた名目額 × COST_PIPS/2（片道）です。H3 は1取引ごとに往復の COST_PIPS をかけています。

## 3. 事前固定の判定基準（結果を見る前に固定）

1. コスト控除後の年率リターンが、4区分 {D, C} × {IS 2012–2018, OOS 2019–2024} のすべてでプラスであること。
2. 2012–2024年の週次ネットリターンの t値が 2.0 以上であること。H1・H3 は D と C を合わせた系列、H2 は18銘柄全体の系列で判定します。
3. 年率ボラティリティ8%に合わせたとき、累積リターン ÷ 最大ドローダウンが 3 以上であること。
4. 組み替え回数または取引数が100以上であること。
5. 使った通貨・銘柄の60%以上で、損益への寄与がプラスであること。

## 5. 合格案：なし

合格案がないため、「取引しない条件」の分析（ボラティリティ局面、ドローダウン停止、組み替え曜日、相関急上昇）、5%/8%運用シミュレーション、ブロック・ブートストラップによる最大DDの分布、EA 実装の概略は実施していません。結果を見たあとで条件を足して合格に近づける作業は、過剰最適化になるため行いません。

## 6. 最も近い案とその弱点

**事前に決めた案の中で最も近いのは H1b（1週リバーサル）です。** 5基準のうち④と⑤の2つを満たしました。

- 弱点：
  - USD建てペアで実装した D 群は IS +3.1%、OOS +0.7%（年率、8%ボラ換算）とプラスでした。しかし、同じ考え方をクロスで実装した C 群はほぼゼロ（−0.03% / −0.09%）でした。
  - D 群の利益は主に USD・EUR・CAD・CHF からで、「通貨全般の短期の行き過ぎの戻り」とは言い切れません。
  - 毎週の売買量が多く（名目の約2.6倍／週）、コストを2倍にすると全体はマイナスです。
  - 2021–2024年は4年中3年がマイナスでした。

**参考（事後の観察で、合格候補ではありません）：H1a の符号を逆にした場合**

- H1a は4区分すべてが一貫してマイナスでした。そこで、売買の向きを逆にした「12週リバーサル」も試算しました。
  - コスト（逆向きでも同じだけかかります）を控除した後の4区分：D・IS +4.5%、D・OOS +2.4%、C・IS +3.3%、C・OOS +3.1%
  - t値 1.53、累積/DD 3.8、最大DD −12.8%、横ばい最長 30か月
  - t値の基準（2.0）は満たしません。
- これは結果を見てから向きを変えたものです。今回の7本の検定のうち1本で |t|≈2 が出る確率は偶然でも約3割あります。そのため、この結果を合格扱いにはできません。
- 次のラウンドで「中期の通貨リバーサル」を事前登録して検証するとしても、2012–2024年のデータは既に見てしまっています。本当の検証になるのは 2025年以降の新しいデータだけです。

**H2（トレンドフォロー）について**：

- 全体の利益は SNB の1週（2015年1月）に依存しています。それ以外の期間は2016年以降ほぼ横ばいから下落でした（107か月高値を更新できていません）。
- 2012–2024年の主要通貨では、時系列モメンタムに優位性は見られませんでした。

**H3（日中季節性）について**：

- コストを除いても効果がほぼありません（t値 0.94）。1日2回の往復コストを払える大きさではありません。
- 元の研究の時期（1990–2000年代）に比べ、この効果は消えているか、ごく小さいと考えられます。

**スワップについての注意**：

- 今回のバックテストはスワップを一切含んでいません。
- H2 や H1 のように数週間から数か月持ち続ける戦略では、スワップの影響が大きくなります。例えば JPYクロスの買いはプラスのスワップを受け取り、売りは支払います。
- そのため、実際の口座では今回の数値から、年率で数%単位の上振れ・下振れがありえます。どれだけ変わるかは期間・方向・ブローカーによって異なります。

## 7. 限界

- **データ**：histdata の価格は1つの配信元の値です。実際のブローカーの約定価格・スプレッドとは異なります。
  - 日曜17:00 EST の始値で約定する前提ですが、実際の週明け直後はスプレッドが非常に広くなります。実運用なら月曜の欧州時間に組み替える必要があり、その場合の結果は検証していません。
- **時刻**：EST 固定（夏時間なし）で時間帯を定義しています。夏の間は、実際の各市場の開始時刻と1時間ずれます（H3 に影響します）。
- **損益の計算**：各ペアの価格変化率 × 名目額で計算しており、決済通貨（円やポンドなど）から口座通貨への換算は無視しています。
  - H1 の通貨別寄与は、通貨バスケットに対する収益に、コストを持ち高の変化量に比例して割り振った近似値です。
- **ボラティリティの調整**：年率8%への調整は、成績比較のための事後の一定倍率です（H2 は事前の目標ボラ8%で運用したうえで、さらに事後に調整しています）。実運用では事前推定になるため、実際のボラティリティは目標からずれます（H2 の実績は 9.8〜17.8%）。
- **期間**：
  - H2 は12か月の計算期間が必要なため、IS が実質2013年からです。
  - AUDJPY は2012年10月からのデータです。H1 の C 群では、それ以前の AUD の強さを EURJPY/EURAUD から作りました。売買には使える銘柄だけを使っています。
- **多重検定**：第0ラウンド（27案＋フィルタ69個）と第1ラウンド（7本）で、多くの検定を行っています。単独で t≈2 の結果が出ても、偶然である可能性を差し引いて見る必要があります。
- **コストとスワップ**：コストは COST_PIPS の固定値で、指標発表時のスリッページの広がりは入っていません。スワップは未考慮です。
