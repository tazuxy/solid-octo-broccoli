# 第13ラウンド 事前登録：上位足のチャートパターン（ダブルトップ／ボトム、三尊／逆三尊）

固定日: 2026-11-04（計算の前にコミット）。ご依頼者の提案。判定は改訂案A（第10ラウンドと同じ）。

## 文献
- Chang & Osler (1999, Economic Journal): ドルの日足（1973〜94年）で三尊のルールは利益が出るが、より単純なルールに劣る。
- ダブルトップ／ボトムの FX での厳密な検証は見つからなかった。実務家の検証は、山と谷を後から決めているもの（先読み）が多い。
- これまでのラウンドでは、ダウ理論の高値・安値、水平線、トレンドラインは試したが、三尊・ダブルトップは試していない。

## 足と山・谷の決め方（先読みなし）
- 5分足から4時間足と日足を作り直す。このとき 16:55〜17:30 EST の5分足は除く（売値だけのデータのロールオーバーの癖を避けるため）。日足は 17:00 EST 区切り（実質 17:30〜16:55）。
- ATR(14) はその時間足のもの。
- 山・谷（ジグザグ）: 上昇中は高値の最大を追い、終値がその最大から 2×ATR 以上下がった足で、その最大を「山」として確定する。下降中も同様に「谷」を確定する。確定した山・谷と、確定していない今の区間の最大・最小だけを使う。

## 形とエントリー（足の終値で判定し、次の足の始値で約定）
- **ダブルトップ（売り）**: 確定済みの 山 P1 → 谷 T のあと、今の区間の最高値 P2 が |P2 − P1| ≤ 0.5×ATR、P2 − T ≥ 1×ATR。終値が T を下に割ったら売り。T の確定から60本以内。P2 が P1 + 0.5×ATR を超えたら無効。
- **ダブルボトム（買い）**: 上下を逆にしたもの。
- **三尊（売り）**: 確定済みの 左肩 LS → 谷 T1 → 頭 H → 谷 T2 のあと、今の区間の最高値 RS が RS < H、H − max(LS, RS) ≥ 0.5×ATR、|LS − RS| ≤ 1×ATR、RS − T2 ≥ 1×ATR。ネックライン（T1 と T2 を結ぶ直線）を終値が下に割ったら売り。T2 の確定から60本以内。RS が H を超えたら無効。
- **逆三尊（買い）**: 上下を逆にしたもの。
- ATR は、ネックラインを割った足の値を使う。

## 決済（教科書どおりの1種類だけ）
- 損切り: ダブル = 2つの山の高い方 + 0.2×ATR、三尊 = 右肩 + 0.2×ATR（買いは逆）。
- 利確: 形の高さの分（ダブル = ネックラインから「山 − ネックライン」の分。三尊 = ネックラインから「頭 − 頭の時点のネックライン」の分）。
- 時間切れ: エントリーから60本目の足の始値。
- 足の中で損切りと利確の両方に届いたら損切りを先とする。足の始値が越えていれば始値で約定。
- 1つのペア・1つの仮説につき、同時に1ポジション。
- R = 損切りまでの幅。

## 仮説（4つ）
- P1 ダブルトップ／ボトム（4時間足）
- P2 ダブルトップ／ボトム（日足）
- P3 三尊／逆三尊（4時間足）

- 最終判定: ふるいを通った案だけ 2022〜2024年を1回だけ見て、平均 > 0、かつ 2005〜2024年の t ≥ 3.0。
