# 手法2の損切りの位置（結果）

事前登録: `r11_m2_stop_prereg.md`。コード: `research/code/r11_m2_stop.py`。

## 結論
- **事前に決めた選び方で、損切りは「エントリー価格 + 1R」（R = 日足 ATR(14) の 0.25倍、中央値で約 22 pips）になりました。**
- 1回の最大の負けが −343.5 pips（−24.6R）から −70.6 pips（−1.08R）に縮みます。平均は損切りなしの 93% を残します（2005〜21年 +0.123R → +0.114R、t 3.20 → 4.23）。
- 大負けの原因は、ほぼ **日本の政策・介入のニュース** でした（下の表）。ご心配の「予期せぬニュース」はこの手法の最大のリスクで、損切りはそれに効きます。
- EA（`ea/GotobiPostFix_USDJPY.mq5`）の `InpStopR` の初期値を 1.0 にしました。損切りを置いた場合、`InpRiskPercent` は「損切りにかかったときの損失」になります。1R の損切りではロットは今までと同じです。

## 注意
- 1R の損切りは、全体の約4分の1の取引でかかります。普段の値動きの中にある近い損切りですが、それでも平均の 93% が残りました。
- 2005〜21年の histdata では、最大DD（R）は損切りなしより大きくなりました（−24.6 → −38.5R）。小さな損切りが続く時期があるためです。一方、FXCM（2012〜24年）と 2022〜24年では小さくなりました。
- **介入のような急変では、実際の約定は損切りの価格よりかなり悪くなることがあります。** 5分足では1足の中の動きが分からないので、ここでの結果（最悪 −70.6 pips）は楽観的かもしれません（要確認）。
- 次に検証する価値がある点: 大負けの多くが、介入と日銀の決定の日でした。日銀の金融政策決定会合の発表日（昼ごろ、保有時間中）に取引しない、という条件は理由がはっきりしています。日程を取得して、事前登録のうえで検証できます。
