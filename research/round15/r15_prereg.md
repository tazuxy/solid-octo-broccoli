# 第15ラウンド 事前登録：ORZ 式の「上位足で場所 → 下位足で確認して入る（確認できなければ見送り）」

固定日: 2026-11-04（計算の前にコミット）。元資料: `research/orz/orz_rules.md`（ルールの抽出）、`research/orz/orz_trades.md`（公開トレード345件の集計。本人が選んだ記録で、優位性の証明には使わない）。
パラメータは作者の記述と公開トレードの中央値から1組だけ決め、調整しない。

## 共通
- データ: histdata 売値の5分足（固定 EST）。上位の足は5分足から作り、16:55〜17:30 EST の5分足は除く。対象: 17ペア＋ゴールド（第13ラウンドと同じ）。
- コスト: 往復 0.5 pips（ゴールド 0.30 ドル）。約定は次の足の始値。損切りと利確が同じ足なら損切りを先。
- 週末: 金曜 12:00 EST 以降は新規なし。金曜 16:00 EST に持ち越しを決済（98284「週末は持ち越さない」）。
- R = 損切りまでの幅。1つの銘柄・1つの仮説で同時に1ポジション。
- 選別 2005〜2021年、最終 2022〜2024年（1回だけ）、判定は改訂案A（ふるいの t は下の各案のとおり）。

## 軸足の指標
- SMA20・SMA50・SMA100（終値）、ATR(14)。
- 山・谷: 第13ラウンドと同じ先読みなしのジグザグ（終値が 2×ATR 戻ったら確定）。
- 上昇トレンド（90117 の最小条件）: SMA100 が10本前より高い、直近5本の終値がすべて SMA100 より上、確定した最後の2つの山が切り上げ、最後の2つの谷も切り上げ。下降は逆。

## O1 押し目買い・戻り売り（軸 1時間足、下位足 5分足）／ O2 同じ（軸 4時間足、下位足 15分足）
- 待ちの開始（買い）: 1本前の軸足で上昇トレンド。今の軸足の安値が SMA50 + 0.2×ATR 以下に入る（SMA への押し）。ゾーン下限 = SMA50 − 0.5×ATR（待ち開始時点の値で固定）。
- 下位足の確認（買い。49747・94036・7682）: 待ち開始の後、下位足のフラクタル（前後2本より低い安値、2本後に確定）で谷 L1 → 山 H → 谷 L2（L2 ≥ L1 − 0.1×ATR軸、つまり安値の更新が止まる）。その後、下位足の終値が H を上に抜けたら、次の下位足の始値で買い。L2 が L1 − 0.1×ATR軸 より下なら、L2 を新しい L1 として数え直す。
- 取り消し: 下位足の終値がゾーン下限を割る、または待ち開始から軸足12本たっても合図がない（O1 = 12時間、O2 = 48時間）。取り消し・決済の後は、軸足の終値が SMA20 より上に戻るまで次の待ちを始めない。
- 損切り: min(L1, L2) − 0.1×ATR軸。利確: 押しの前の最後の確定した山（前回高値）。**利確までの幅が損切りの幅の2倍未満なら見送り**（8972）。
- 時間切れ: O1 72時間、O2 10日（週末の決済を優先）。
- 売りは上下を逆にしたもの。
- ふるいの t ≥ 2.5（新しい情報源からの仮説）。

## O3 レンジの逆張り（軸 1時間足、下位足 5分足）
- レンジ: SMA100 の10本の変化が 0.5×ATR 未満。確定した最後の2つの山の差が 0.5×ATR 以内（上限ゾーン = その2つの高い方 + 0.2×ATR 〜 低い方 − 0.3×ATR）、最後の2つの谷の差も 0.5×ATR 以内（下限ゾーンも同様）。
- 待ちの開始（売り）: 軸足の高値が上限ゾーンに入る。下位足の確認は O1 の上下を逆にしたもの。取り消し: 下位足の終値が上限ゾーンの上を抜ける、または12時間。
- 損切り: 下位足の2つの山の高い方 + 0.1×ATR。利確: 下限ゾーンの上端。2倍未満なら見送り。時間切れ 72時間。買いは逆。
- 過去に不合格だった「水平線のゾーンで逆張り」（第7・8ラウンド）、資源国クロスの逆張り（第10ラウンド H4）の入り方を変えた再挑戦にあたるので、**ふるいの t ≥ 3.0**。

## O4 手法2に下位足の確認を足す
- ゴトー日（手法2と同じ）、09:55 JST にすぐ売らず、09:55〜10:55 JST の5分足で「フラクタルの山 H1 → 谷 L → 山 H2（H2 ≤ H1 + 0.1×R）→ 終値が L を下に抜ける」を待って、次の5分足の始値で売る。1時間以内に合図がなければ、その日は見送り。
- 損切り・決済は手法2のまま（エントリーから 1R 上、15:00 JST に決済）。R は手法2と同じ（日足 ATR(14) の 0.25倍）。
- 判定: ゴトー日1日あたりの平均R（見送りは 0）が、手法2（すぐ売る、損切り 1R）より高いこと。2005〜2016年で高い → 2017〜2021年でも高い → 2000〜2004年でも高い、の3つをすべて満たせば採用。2022〜24年は参考。
