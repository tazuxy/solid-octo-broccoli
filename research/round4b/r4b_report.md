# 第4ラウンド追加検証（r4b）：スプレッド0.5 pips での再評価と「ゴトー日の前日に買う」案

対象データ：第4ラウンドと同じです（histdata の1分足から作った5分足、2005〜2024年、EST＝UTC−5 固定、Bid のみ）。**日本時間（JST）＝ EST ＋ 14時間**（通年）。スワップは含めていません。

**コストの前提（今回の変更点）**：ご指示により、**往復コストを全通貨ペア一律 0.5 pips** としました（Bid だけのデータなので、買いは Ask＝Bid＋0.5 pips で約定し、Bid で決済する、と同じ扱いです。売りも同じく 0.5 pips を差し引きます）。**0.5 pips はご依頼者の仮定です。** 第4ラウンドの基準（USDJPY 1.0 pip、他の通貨はそれ以上、S1 はその2倍）より大幅に低い値です。2倍のコスト（1.0 pip）でも基準を満たすかを必ず確認しています。参考として 0.3／0.7／1.0 pips も示します。それ以外のルールは第4ラウンドから一切変えていません（第4ラウンドの取引データをそのまま使い、コストだけを差し替えました。新しいコードで a・b・c・c2 を作り直し、第4ラウンドと取引数・損益が完全に一致することを確認済みです）。

---

## 1. 結論

1. **ゴトー日前日買いの E1・E2 は、事前に決めた基準をすべて満たしました（0.5 pips でも 1.0 pip でも合格）。**
   - E2（前日 22:00 JST に買い → ゴトー日 09:55 JST に決済）：1回平均 +4.66 pips（コスト後）、平均 +0.191R、t値 3.90、合計R÷最大DD 6.5、3期間すべてプラス。1.0 pip でも t値 3.40、比 5.2。
   - E1（前日 15:00 JST に買い → 09:55 JST）：平均 +0.224R、t値 3.63、比 6.6。1.0 pip でも合格。
   - E3（前日 09:55 → 当日 09:55、24時間保有）は t値 1.99 で僅差の不合格。E4（前日の 08:00→09:55、対照）はほぼゼロで不合格。
   - EA は、t値が最も高く保有時間も短い **E2** で作りました（`r4b_EA.mq5`、未コンパイル）。
2. **値上がりの中心は「ゴトー日前夜の NY 時間〜翌朝（22:00〜08:00 JST）」と「仲値前（08:00〜09:55）」**です。前日の東京午後（09:55〜15:00）はむしろ下がります。ゴトー日でない日の同じ時間帯にはこの値上がりがないため、ゴトー日に特有の動きと言えます。
3. **ただし注意点が大きいです。**
   - ゴトー日が**月曜（週末をまたぐ保有）**のときはマイナス、**5日と月末**のゴトー日はほぼゼロです。利益は 10・15・20・25・30日（の前夜）に偏っています。
   - 1回の値動きのばらつきが大きく（標準偏差 約47 pips）、**0.5%/R のリスクでは最大DD 約21%、資産が最高値を更新できない期間が約4年（1,456日）**ありました。「低ドローダウン」を目指すなら、リスクを半分（0.25%/R）にするか、2R の損切りを置く案（最大DD 約7%、年率 約2.8%）になります。
   - 多くの案を同じデータで試した後の結果です（第5章）。8案で補正すれば有意ですが、第0〜4ラウンド全体の試行回数を考えると「確実」とは言えません。
4. **S2 の a・b・c・c2（第4ラウンドの案）は、0.5 pips でも全て不合格**です。最も近い b（ゴトー日 08:00→09:55）は 0.5 pips では ①〜③ を満たします（t値 3.92、比 5.1）が、2倍の 1.0 pip で比 2.47 となり ④ で不合格です。
5. **S1（朝スキャ）は、RSI／中心線の1案が 0.5 pips で形式上は合格**しました（t値 14.8、比 17.3、1.0 pip でも平均R プラス）。しかし、
   - グロス利益の **64〜72% がロールオーバー直後の 17:30〜17:55 EST（JST 07:30〜07:55）**に集中しており、この時間帯を除くと**4案すべて基準を大きく下回ります**（RSI／中心線は比 1.54、2019-2024 がマイナス）。
   - この時間帯に17通貨ペアすべてを 0.5 pips で取引できるとは考えにくく、また Bid だけのデータによる見かけの利益を取り除けません。
   - そのため、**S1 については EA・資産曲線の作成は行わず、「形式上の合格だが実運用は推奨しない」**と判断しました（これは私の判断です。ご希望があれば同じ手順で作成します）。

**S1 についての補足**
- 0.5 pips は全17ペア共通の仮定です。実際には、ロールオーバー直後（JST 早朝）のスプレッドは、EURUSD でも 1〜3 pips、GBPCHF・EURAUD・NZDJPY などのクロスでは 3〜10 pips 以上に広がることが普通です。この時間帯に 0.5 pips で約定できる前提は、現実的ではないと考えます。
- Bid だけのデータの問題：ロールオーバーでスプレッドが広がると Bid が下がり、戻ると Bid が上がるため、「売られすぎ→戻り」に見える動きが生じます。このデータでは Ask がないので、この影響を取り除けません。
- 追加の確認：17:30〜17:55 EST の利益は、米国の夏時間（NY のロールオーバーが 16:00 EST）と冬時間（17:00 EST）で**ほぼ同じ**でした（RSI／中心線：冬 +3.55、夏 +3.66 pips）。また、histdata の価格自体が、季節に関係なく毎日 17:00 EST 前後で足の欠落と値幅の拡大を示しています。つまり、このデータの提供元は通年 17:00 EST を日の区切りにしており、17:30〜17:55 は常に「その区切りの直後」です。本当の値動きなのか、データの区切りによる見かけなのかは、このデータでは判別できません。
- 方向別では、売りも 17:30〜17:55 で +3.33 pips（RSI／中心線）あり、Bid の持ち上がりだけでは説明しきれない部分もあります。ただし、その場合も実際の約定は広いスプレッドで行われます。

## 3. ゴトー日の前日に買う案（E1〜E4、事前登録）

### 3.1 定義（結果を見る前に固定）

- ゴトー日 G：JST の日付が 5・10・15・20・25・30日、または月末の最終営業日。土日なら直前の金曜日に繰り上げ。**日本の祝日カレンダーは使っていません**（平日はすべて営業日扱い）。

## 4. 「取引しない条件」の確認（E2、合否には影響しない追加検討）

採用条件（事前に決定）：3期間すべてで最大DD（R）が小さくなり、かつどの期間の平均R もマイナスにならないこと。

- F4 は週末の窓開けリスクという経済的な理由はありますが、第3.3節で月曜のゴトー日が弱いことを見た後に作った条件なので、採用しません。EA には入力項目として残し、初期値はオフです。
- 結果として、**採用した「取引しない条件」はありません。**

## 5. 多重検定の注意

- 仲値・ゴトー日系で試した案は、第4ラウンドの a・b・c・c2 と今回の E1〜E4 の **合計8案**です。
- 0.5 pips で t値が最も高いのは b（3.92、片側 p＝0.000045）、次が E2（3.90、p＝0.000048）、E1（3.63、p＝0.00014）です。
- **ボンフェローニ補正（8案）**：補正後 p は b 0.0004、E2 0.0004、E1 0.0011。いずれも 5% 水準を十分に下回ります（8案での片側5%の境界は t＝2.50）。
- ただし、
  - 第0〜第3ラウンドの多数の案、第4ラウンドの S1（4案）、今回の時刻の近傍チェック（参考の14通り）、コスト前提の変更（1.0 → 0.5 pips）も含めると、実際の試行回数は8より大幅に多いです。
  - 補正後の境界（片側5%）：20案 t＝2.81、50案 3.09、100案 3.29、200案 3.48、500案 3.72。E2（3.90）は500案相当でもぎりぎり残りますが、E1（3.63）は200案を超えると届きません。
  - E1〜E3 と b は同じ「G の 08:00〜09:55」を含むため、独立した8回の検定ではありません。
  - E1〜E4 の案自体が、第4ラウンドで b の結果を見た後に考えられたものです。
- 以上から、**E2 の結果は統計的には偶然とは考えにくい水準ですが、「同じデータを何度も見た後の発見」である点は割り引いて考える必要があります。** 新しい期間（2025年以降）での確認、またはデモ口座での運用確認をお勧めします。
- S1 の t値（RSI／中心線 14.8）は多重検定では問題になりません。S1 の問題は統計ではなく、コストとデータ（Bid のみ）の問題です。

### 6.2 EA（`r4b_EA.mq5`）

- ルール：ゴトー日 G の前の営業日 D の **22:00 JST に買い**、G の **09:55 JST に決済**。1回に1ポジション。
- 主な入力項目：
  - ブローカーのサーバー時間の GMT 差（冬時間）と夏時間ルール（米国式／欧州式／なし）。初期値は「GMT+2、米国式夏時間」（NY クローズ型の一般的な MT5 業者）。ライブでは TimeGMT() から自動算出する選択肢もあります。
  - エントリー時刻・決済時刻（JST、文字列で入力）。15:00 にすれば E1 になります。
  - 追加の休業日リスト（JST、"yyyy.mm.dd" をカンマ区切り）。休業日は営業日から外し、ゴトー日の繰り上げと前日の判定に使います。**空欄のままが今回の検証と同じ条件**です。
  - 最大スプレッド（初期値 1.0 pips。超えていれば許容時間内で再試行し、だめなら見送り）。
  - ロット：資産の何% を 1R（＝0.25×日足ATR14）に当てるか（初期値 0.5%）。損切り（R の倍数、初期値 0＝なし）を設定した場合は、損切り時の損失がその%になるように計算します。固定ロットも選べます。
  - 検証で不採用だった条件（年末年始・GW、リスクオフ、週末保有）はスイッチとして残し、初期値はオフです。
  - 安全策：保有が 72時間を超えたら決済。
- 前提（この環境ではコンパイル・テストできていません）：
  1. MetaEditor でのコンパイル確認が必要です（`CTrade::SetTypeFillingBySymbol` は新しいビルドが必要）。
  2. JST＝GMT＋9（夏時間なし）。夏時間の切替時刻付近の1時間は、判定が最大1時間ずれる可能性があります。
  3. 日足 ATR はブローカーの日足を使います。検証は NY 17:00 区切り（週5本）の日足です。GMT 0時区切りの業者では日曜足が入り、ATR（＝ロット数）が少し変わります（売買のタイミングは変わりません）。
  4. 検証はその時刻ちょうどの5分足の始値で約定、往復 0.5 pips、スリッページなし、スワップなし。22:00 JST（NY 午前）は通常スプレッドが狭い時間帯ですが、09:55 JST の決済時のスプレッドは業者ごとに確認してください。
  5. ゴトー日が月曜の場合は週末をまたいで保有します（週明けの窓開けリスク）。
  6. 許容時間内にティックがない・スプレッドが広い場合、そのゴトー日は見送りになります。

## 7. 限界

- **0.5 pips はご依頼者の仮定**です。第4ラウンドでは USDJPY 1.0 pip を基準にしていました。E2 は 1.0 pip でも合格するので、この仮定への依存は小さいですが、S1 と S2 の b は仮定に強く依存します。
- **Bid だけのデータ**：実際のスプレッドの変化（特にロールオーバー前後）を再現できません。S1 の利益の大部分は、この影響を受けやすい 17:30〜17:55 EST にあります。
- **日本の祝日を考慮していません**：祝日に当たるゴトー日（例：5月5日、11月23日など）は本来前営業日に繰り上がり、仲値の公表もありません。年末年始・GW を除くと E2 の成績は少し良くなりました（第4章 F3）。
- **スワップは含めていません**（USDJPY の買いは概ね受け取り側。ただしゼロ金利期はほぼゼロ）。
- 損切りなしの保有を前提にしているため、急変時（例：2008年、2016年の一部）の1回の損失が大きくなりえます。最悪の1回は資産の −3.8%（0.5%/R の場合）でした。
- 2023年の USDJPY データに欠損があり、その年の取引数が少なくなっています。
- 仲値の需給の効果は近年弱まっている可能性があります（E2 の 2019〜2024年は平均 +0.111R で、それ以前の約半分）。
- 多くの案を同じデータで試した後の結果です（第5章）。将来も同じ成績になる保証はありません。
