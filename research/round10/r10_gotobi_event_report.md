# 手法1：保有中の大きな経済指標の検証結果

事前登録: `r10_gotobi_event_prereg.md`。コード: `research/code/r10_gotobi_event.py`。集計: `r10_gotobi_event_variants.csv`。

## 1. 結論

- **事前に決めた規則での判断は「変えない」です。** 見送りの条件を満たした期間は 0/3、ばらつきの条件だけを満たした期間は 1/3 でした。
- 保有中に雇用統計・CPI・FOMC がある取引は、3期間のうち2期間で、ない取引より**平均が高い**結果でした（2000〜04年 +28.0 対 +4.2 pips、2005〜24年 +8.5 対 +6.1 pips）。見送ると、合計も最大DD も悪くなります。
- ばらつきが大きくなったのは 2005〜24年だけでした（標準偏差 73 対 47 pips、1.56倍）。2000〜04年（50 対 47）と 2025〜26年（66 対 58）では、1.2倍未満でした。
- 2025〜26年は「指標あり」が6回だけで平均 −39.9 pips でしたが、回数が少なすぎて判断できません。
- **指標の時刻の注意点**: 米国の 08:30 の指標（雇用統計・CPI）は、米国の夏時間中は日本時間 21:30 で、エントリー（22:00）より前に終わります。保有中に入るのは冬時間（11〜3月ごろ）だけです。このため「保有中に指標あり」は 2005〜24年で 60回（全体の5%）と少数でした。

指標別（2005〜24年）: 雇用統計 19回 +18.6、CPI 16回 −12.6、FOMC 25回 +14.4 pips。

参考（時刻を問わず、D の日付に指標がある取引）: 2005〜24年 142回 +4.29 pips（標準偏差 74.8）、2000〜04年 24回 +21.08、2025〜26年 10回 −31.67。

- **前回提案した「月曜のゴトー日を半分ロット」の効果**（前回は「要確認」としていたもの）:
  - 2005〜24年は、合計を 3% 減らして、最大DD を 25% 小さくします（−766 → −572）。
  - 2000〜04年は、最大DD が 11% 小さくなりました（−726 → −643）。
  - 2025〜26年は、最大DD が少し小さくなり（−454 → −420）、合計は悪化しました（−38 → −79）。この期間は月曜の取引が13回で平均 +6.4 pips と、たまたまプラスでした。

## 4. 解釈（推測を含む）

- 大きな指標の日は、値動きの向きがゴトー日の実需と無関係なので、「ばらつきが増えるだけ」と予想していました。結果は、2つの期間で平均がむしろ高く、ばらつきも一貫して大きくはありませんでした。理由は分かりません（要確認）。指標でドル円が大きく動くと、輸入企業が仲値でドルを買い急ぐ、といった説明も考えられますが、検証していません。
- 「指標あり」は少数（2005〜24年で 60回）なので、どちらの向きにも強い結論は出せません。事前の規則どおり、ルールは変えません。

## 5. 限界

- 雇用統計・CPI の発表日は、BLS のページを WebFetch で読み取った一覧です。土日の日付がない、年12回そろっている、金曜以外の日付は休日の前倒しと政府閉鎖の遅れで説明がつく、ことは確認しましたが、1件ずつの照合はしていません（要確認）。
- 対象の指標は米国の3つだけです。日本の指標（日銀短観 8:50 JST など）や、ほかの米国指標（小売売上高・ISM など）は入れていません。
- 未使用の期間がないので、どの判断も使用済みのデータに基づきます。
